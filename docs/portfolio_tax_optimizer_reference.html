Production Risk Controls

✓ Single managed E*TRADE account (DRIP disabled); honor E*TRADE adjusted basis.
✓ 30-day lookback: prior-30d buy blocks loss sale unless recent buy lot is also sold in full.
✓ 30-day forward do-not-buy block after any executed or proposed loss sale.
✓ Tax lot eligibility revalidated at order approval.
Policy assumes approved distinct ETF pairs are not substantially identical; exact security repurchases remain restricted.
